# 回滚手册（LDPlayer14 · 属性伪装 + L2 环境变更）

目标实例：LDPlayer14 index 1（adb `emulator-5556`）
备份目录：`runs/backup_20261103_144420/`（L1 整机配置）、`runs/l2/aqcenter_data_backup/`（L2 app 数据）

> 原则：运行时层属性（fingerprint/device/serial/qemu/description/abi 等）**重启即自动回退**到 LDPlayer 开机默认值，无需逐项回滚；持久层（IMEI/MAC/型号等）用下面的命令改回原值。

## 一键回滚（把持久层改回原值）

```powershell
& 'D:\leidian\LDPlayer14\ldconsole.exe' modify --index 1 `
  --manufacturer REDMI --model 25102RKBEC `
  --pnumber "" --imei 869169021589125 --imsi 460007563256525 `
  --simserial 89860095026598213139 --androidid 1abe308c2c99ae10 --mac 00DB4FC8A1BD

& 'D:\leidian\LDPlayer14\adb.exe' -s emulator-5556 shell settings put secure android_id 3d9813f16f475cc9
& 'D:\leidian\LDPlayer14\adb.exe' -s emulator-5556 shell settings put secure bluetooth_name 25102RKBEC

# 重启：运行时层属性（fingerprint/device/qemu/serial/abi 等）随之恢复开机默认值
& 'D:\leidian\LDPlayer14\ldconsole.exe' reboot --index 1
```

## 逐项回滚

### 机型身份（持久层）

```powershell
# 型号/制造商：改回 LDPlayer 默认
& 'D:\leidian\LDPlayer14\ldconsole.exe' modify --index 1 --model 25102RKBEC --manufacturer REDMI
```

### 机型身份（运行时层：重启即回退）

```powershell
# 无需逐条回滚；重启后自动回到：

#   ro.build.fingerprint = Xiaomi/unicorn/unicorn:14/UQ1A.240205.09211156/ucsm.20260921.115630:user/release-keys
#   ro.build.description = unicorn-user 14 UQ1A.240205.09211156 ucsm.20260921.115630 release-keys

& 'D:\leidian\LDPlayer14\ldconsole.exe' reboot --index 1
```

### 蓝牙地址 / WiFi 名

```powershell
# 蓝牙地址：重启自动回退 DA:4C:10:DE:17:02（无需操作）；若当前 boot 想立即回退：
& 'D:\leidian\LDPlayer14\adb.exe' -s emulator-5556 shell settings put secure bluetooth_address DA:4C:10:DE:17:02

# WiFi 名（SSID）：LDPlayer 虚拟 AP 每 boot 随机生成，无固定值可回滚；重启即可。
```

## L2 新增变更的回滚

### root 开关（持久层，重启生效）

```powershell
# L2 期间在 开 → 关 之间切换过。恢复 L2 实验前的状态（关）：
& 'D:\leidian\LDPlayer14\ldconsole.exe' modify --index 1 --root 0
& 'D:\leidian\LDPlayer14\ldconsole.exe' reboot --index 1

# 若需临时开 root（L1 时代状态）：
# & 'D:\leidian\LDPlayer14\ldconsole.exe' modify --index 1 --root 1 ; & ... reboot --index 1
```

### 99账号中心 app 数据（L2 清空过一次）

```powershell
# 备份在本地：runs/l2/aqcenter_data_backup/（2026-11-03 16:45 左右，pm clear 之前 copy 的完整 /data/user/0/com.nd.aqcenter）
# 也可从设备残留恢复：/sdcard/aqcenter_data_backup/（若未删）
# 恢复（需 root）：
& 'D:\leidian\LDPlayer14\ldconsole.exe' modify --index 1 --root 1
& 'D:\leidian\LDPlayer14\ldconsole.exe' reboot --index 1
# 等开机后：
& 'D:\leidian\LDPlayer14\adb.exe' -s emulator-5556 shell pm clear com.nd.aqcenter
& 'D:\leidian\LDPlayer14\adb.exe' -s emulator-5556 shell "su -c 'cp -a /sdcard/aqcenter_data_backup/. /data/user/0/com.nd.aqcenter/'"
& 'D:\leidian\LDPlayer14\adb.exe' -s emulator-5556 shell "su -c 'chown -R u0_a72:u0_a72 /data/user/0/com.nd.aqcenter'"
```

> 注意：若不恢复，99账号中心下次启动会重新弹隐私协议并重建数据库（行为等同首次安装），对游戏登录无功能损失，仅丢本地缓存。

### 运行时改过的 CPU ABI（重启即回退）

```powershell
# L2 用 setprop 改过 ro.product.cpu.abi / ro.product.cpu.abilist；重启自动恢复 x86_64 原值。
# 若当前 boot 立即回退：
& 'D:\leidian\LDPlayer14\ldconsole.exe' setprop --index 1 --key ro.product.cpu.abi --value x86_64
& 'D:\leidian\LDPlayer14\ldconsole.exe' setprop --index 1 --key ro.product.cpu.abilist --value 'x86_64,arm64-v8a,x86,armeabi-v7a,armeabi'
```

### 尝试改名 /system/xbin/su（失败，无残留）

- L2 曾执行 `mv /system/xbin/su /system/xbin/su.bak`，报 `Read-only file system` **未生效**，无残留需要回滚（真实回显见 `L2执行记录.md` §3#3）。

### 整机配置兜底（改崩时用）

```powershell
# 停止实例，还原配置文件，再启动
& 'D:\leidian\LDPlayer14\ldconsole.exe' quit --index 1
Copy-Item 'runs\backup_20261103_144420\leidian1.config.orig' 'D:\leidian\LDPlayer14\vms\config\leidian1.config' -Force
Copy-Item 'runs\backup_20261103_144420\leidian.vbox.orig' 'D:\leidian\LDPlayer14\vms\leidian1\leidian.vbox' -Force
& 'D:\leidian\LDPlayer14\ldconsole.exe' launch --index 1
```
