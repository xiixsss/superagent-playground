# L1 回滚手册（LDPlayer14 · 属性伪装）

目标实例：LDPlayer14 index 1（adb `emulator-5556`）
备份目录：`runs/backup_20261103_144420/`

> 原则：运行时层属性（fingerprint/device/serial/qemu/description 等）**重启即自动回退**到 LDPlayer 开机默认值，无需逐项回滚；持久层（IMEI/MAC/型号等）用下面的命令改回原值。

## 一键回滚（把持久层改回原值）

```powershell
& 'D:\leidian\LDPlayer14\ldconsole.exe' modify --index 1 `
  --manufacturer REDMI --model 25102RKBEC `
  --pnumber "" --imei 869169021589125 --imsi 460007563256525 `
  --simserial 89860095026598213139 --androidid 1abe308c2c99ae10 --mac 00DB4FC8A1BD

& 'D:\leidian\LDPlayer14\adb.exe' -s emulator-5556 shell settings put secure android_id 3d9813f16f475cc9
& 'D:\leidian\LDPlayer14\adb.exe' -s emulator-5556 shell settings put secure bluetooth_name 25102RKBEC

# 重启：运行时层属性（fingerprint/device/qemu/serial 等）随之恢复开机默认值
& 'D:\leidian\LDPlayer14\ldconsole.exe' reboot --index 1
```

## 逐项回滚

### 机型身份（持久层）

```powershell
# 型号/制造商：改回 LDPlayer 默认
& 'D:\leidian\LDPlayer14\ldconsole.exe' modify --index 1 --model 25102RKBEC --manufacturer REDMI
```

### 机型身份（运行时层：重启即回退）

```powershell
# 无需逐条回滚；重启后自动回到：
#   ro.product.device = unicorn
#   ro.product.name  = 25102RKBEC
#   ro.product.board  = 25102RKBEC
#   ro.build.fingerprint = Xiaomi/unicorn/unicorn:14/UQ1A.240205.09211156/ucsm.20260921.115630:user/release-keys
#   ro.build.description = unicorn-user 14 UQ1A.240205.09211156 ucsm.20260921.115630 release-keys
#   ro.boot.qemu = 1
#   ro.build.characteristics = tablet
# 若想当前 boot 立即回退（不重启），逐条 setprop 回原值即可，见 apply_l1_props.ps1 的反向操作。
& 'D:\leidian\LDPlayer14\ldconsole.exe' reboot --index 1
```

### 标识类（持久层）

```powershell
& 'D:\leidian\LDPlayer14\ldconsole.exe' modify --index 1 `
  --imei 869169021589125 --imsi 460007563256525 --simserial 89860095026598213139 `
  --androidid 1abe308c2c99ae10 --mac 00DB4FC8A1BD

& 'D:\leidian\LDPlayer14\adb.exe' -s emulator-5556 shell settings put secure android_id 3d9813f16f475cc9
& 'D:\leidian\LDPlayer14\adb.exe' -s emulator-5556 shell settings put secure bluetooth_name 25102RKBEC
```

### 蓝牙地址 / WiFi 名

```powershell
# 蓝牙地址：重启自动回退 DA:4C:10:DE:17:02（无需操作）；若当前 boot 想立即回退：
& 'D:\leidian\LDPlayer14\adb.exe' -s emulator-5556 shell settings put secure bluetooth_address DA:4C:10:DE:17:02

# WiFi 名（SSID）：LDPlayer 虚拟 AP 每 boot 随机生成，无固定值可回滚；重启即可。
```

### 整机配置兜底（改崩时用）

```powershell
# 停止实例，还原配置文件，再启动
& 'D:\leidian\LDPlayer14\ldconsole.exe' quit --index 1
Copy-Item 'runs\backup_20261103_144420\leidian1.config.orig' 'D:\leidian\LDPlayer14\vms\config\leidian1.config' -Force
Copy-Item 'runs\backup_20261103_144420\leidian.vbox.orig' 'D:\leidian\LDPlayer14\vms\leidian1\leidian.vbox' -Force
& 'D:\leidian\LDPlayer14\ldconsole.exe' launch --index 1
```
