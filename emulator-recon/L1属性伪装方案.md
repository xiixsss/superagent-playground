## 1. 标识类（LD 官方 `ldconsole modify`，成本最低，推荐先做）

```powershell
$c = 'D:\leidian\LDPlayer14\ldconsole.exe'

# 1.1 IMEI（auto=随机合法值；也可指定 15 位）
& $c modify --index 1 --imei auto
# 1.2 IMSI
& $c modify --index 1 --imsi auto
# 1.3 SIM 序列号
& $c modify --index 1 --simserial auto
# 1.4 Android ID（16 位 hex）
& $c modify --index 1 --androidid auto
# 1.5 WiFi MAC
& $c modify --index 1 --mac auto
# 1.6 机型三件套（与目标 fingerprint 配套，勿乱填）
& $c modify --index 1 --manufacturer '<品牌>' --model '<型号>'
# 1.7 电话号码（可选）
& $c modify --index 1 --pnumber '<11位手机号>'
# 1.8 root：项目不依赖客户机 root 时关闭（本项目当前依赖 root，先评估）
& $c modify --index 1 --root 0

# 1.9 重启实例让标识生效
& $c reboot --index 1
# 或：& $c launch --index 1
```

## 2. build.prop / ro.* 类（运行时只读属性，需 `resetprop`，root 下可改、重启失效）

说明：Android 14 的 `ro.*` 属性在 init 早期固化，普通 `setprop ro.*` 会失败；`resetprop`（Magisk 工具）直接改属性区可生效，但**重启即失效**，需开机重跑。

### 2.1 部署 resetprop（一次性，未执行；二进制取自 Magisk 或可信来源）

```powershell
$adb = 'D:\魔域总库\05_成品与资源\moyu_工具\_internal\platform-tools\adb.exe'
# resetprop_x64 需人工提供（Magisk 内置；本机未验证存在）
& $adb -s emulator-5556 push <本机路径>\resetprop_x64 /data/local/tmp/resetprop
& $adb -s emulator-5556 shell "su -c 'chmod 755 /data/local/tmp/resetprop'"
```

### 2.2 逐条改（命令原文；`<...>` 取真实值）

```powershell
$adb = 'D:\魔域总库\05_成品与资源\moyu_工具\_internal\platform-tools\adb.exe'
$rp  = 'su -c /data/local/tmp/resetprop'

# 最高优先：qemu 标志
& $adb -s emulator-5556 shell "$rp ro.boot.qemu 0"
& $adb -s emulator-5556 shell "$rp ro.kernel.qemu 0"

# 设备名（unicorn → 真机 device 名）
& $adb -s emulator-5556 shell "$rp ro.product.device '<真机device>'"
& $adb -s emulator-5556 shell "$rp ro.product.name '<真机name>'"

# SoC 平台（aosp-user → 真 SoC，与 ro.hardware=qcom 对齐）
& $adb -s emulator-5556 shell "$rp ro.board.platform '<真SoC>'"
& $adb -s emulator-5556 shell "$rp ro.product.board '<真board>'"

# fingerprint 全套（brand/device/device:版本/ID/增量:type/tags 五段式，必须互洽）
$fp = '<品牌>/<设备>/<设备>:<release>/<build_id>/<incremental>:<type>/<tags>'
& $adb -s emulator-5556 shell "$rp ro.build.fingerprint '$fp'"
& $adb -s emulator-5556 shell "$rp ro.system.build.fingerprint '$fp'"
& $adb -s emulator-5556 shell "$rp ro.vendor.build.fingerprint '$fp'"
& $adb -s emulator-5556 shell "$rp ro.odm.build.fingerprint '$fp'"
& $adb -s emulator-5556 shell "$rp ro.bootimage.build.fingerprint '$fp'"

# 平板特征 → phone；debuggable → 0
& $adb -s emulator-5556 shell "$rp ro.build.characteristics phone"
& $adb -s emulator-5556 shell "$rp ro.debuggable 0"

# 描述/主机名（可选）
& $adb -s emulator-5556 shell "$rp ro.build.description '<真机description>'"
& $adb -s emulator-5556 shell "$rp ro.build.host '<量产host>'"
```

## 3. L1 能改 & 不能改的边界（诚实口径）

| 项 | L1 是否可改 | 方式 | 持久性 |
|---|---|---|---|
| IMEI/IMSI/SIM serial/Android ID/MAC/model/manufacturer/pnumber/root | ✅ | `ldconsole modify` | 持久（写 config） |
| `ro.boot.qemu`、`ro.product.device`、`ro.board.platform`、fingerprint、`ro.debuggable`、`ro.build.characteristics` | ✅（root） | `resetprop` | 重启失效，需自跑 |
| `phone.productname` 等非 ro 的 phone.* | ⚠️ 可试 | `ldconsole setprop` / `su -c setprop` | 重启被 LD 重建 |
| `/proc/cmdline`（selinux=permissive、nosmap/nosmep） | ❌ | 需引导参数 | L2 |
| 分区 fingerprint / build.prop 构建路径 / ro.treble / bootloader / baseband | ❌ | 需改镜像 | L2 |
| vboxguest/vboxuser、52:54 网关 OUI、x86_64+libhoudini、服务器 CPU | ❌ | hypervisor 本质 | L3，接受 |

## 4. L2+ 只列方案（本任务不动手）

- **L2 镜像级**：离线挂载 `D:\leidian\LDPlayer14\vms\leidian1\` 的 system/vendor 镜像，统一五个分区 fingerprint、删 build.prop 内 `u-emulator/ld_generic/leidian` 注释、`ro.treble.enabled=true`、`ro.bootloader`/`ro.baseband` 给值、改 `/proc/cmdline` 去掉 `nosmap nosmep mitigations=off androidboot.selinux=permissive`、隐藏/改名 `ld*` 二进制、修 `phone.*` 属性生成逻辑。
- **L2 HAL 级**：sensors HAL（5Hz→真实速率分布）、camera HAL（真实参数）、GNSS HAL（真实定位）、RIL/telephony（去哨兵值、统一运营商）、battery health HAL（真实电池画像）。
- **L3 不可行项**：VirtualBox 客户机设备、`hypervisor` CPU flag、x86_64+libhoudini、网关 52:54 OUI——雷电运行机制本身，只能接受或换真机/云真机方案。

## 5. 风险与代价总表

| 操作 | 代价 | 风险 |
|---|---|---|
| `ldconsole modify` 改标识 | 低，官方支持 | 设备指纹突变可能触发游戏风控（建议同一账号固定一套值，别反复换）；MAC/AndroidID 改动影响既有绑定 |
| `--root 0` | 低 | 项目依赖客户机 root 的能力失效（本项目当前 root 可用，先评估） |
| `resetprop` 改 ro.* | 低 | 重启失效；与真机指纹不一致反而更假；`ro.debuggable=0` 可能影响调试 |
| 镜像级 L2 | 高 | 需离线改 vmdk、破坏 AVB/校验、改坏无法开机 |
| L3 | 不可行 | —— |
