# 鲲鹏·一键渗透逆向（小白版）

> 你不需要懂命令、不需要装工具、不需要告诉智能体用什么。把文件丢进 `drop/`，回一句「开始」，等它把报告写完就行。

## 它能做什么

| 你丢进去 | 它自动做什么 | 报告里有什么 |
|---|---|---|
| `.exe` / `.dll` 等 PE 文件 | 查壳、看导入表、反编译/反汇编、找关键函数和 IOC | 这文件干什么、有没有可疑行为、关键地址/偏移 |
| `.apk` / `.xapk` | jadx 反编译、看 manifest、导出组件、硬编码密钥、native so | 攻击面、密钥泄露、隐私/后门迹象 |
| 固件 `.bin` / `.img` 等 | binwalk 解包、提取文件系统、找口令/私钥/后门 | 里面有什么、哪些配置危险、怎么复现 |
| `.ps1` / `.py` / `.js` / `.sh` / 样本 | 静态分析、去混淆、IOC 提取；有沙箱才跑动态 | 行为链、IOC、清除建议 |
| 文本文件，里面写 IP / 域名 / URL | nmap 扫端口、nuclei 扫漏洞、确认后做最小化利用 | 开了什么、有什么漏洞、怎么修 |

一次可以丢多个文件，会按文件名顺序一个一个跑。

## 三步上手

### 第 1 步：丢文件

把要分析的文件（或写着目标的文本）放进仓库根目录的 `drop/` 文件夹。

- 支持 PE、APK、固件、脚本、样本，以及写着 IP / 域名 / URL 的 `.txt`。
- 目标文本一行一个；可在开头写一行授权范围，例如：

  ```
  # 授权范围：仅限以下目标（示例）
  https://example.com
  203.0.113.10
  example.org
  ```

- 文件名尽量保留原样，不要改成 `.txt` 去骗自己——智能体会看文件头，改扩展名没用。

### 第 2 步：说「开始」

在 DeepSeek Harness 里打开这个仓库作为工作区，选择预设 **「鲲鹏·一键渗透逆向」**，在对话框输入：

```
开始
```

不用带路径、不用带参数、不用告诉它用什么工具。它会自己列 `drop/`、识别类型、跑对应管线。

### 第 3 步：等结果（不用盯着）

- 进度看 `runs/INDEX.md`：每个文件一行，状态从 `running` 变成 `done` 或 `failed`。
- 处理时间取决于文件大小/目标数量；大固件、全端口扫描会更久。
- 处理过的文件会移到 `done/<run-id>/`，不会重复跑。

### 第 4 步：看报告

打开 `runs/<时间>-<文件名>/report.md`。固定五段，用大白话写：

1. 一句话结论
2. 发现了什么（按严重度）
3. 关键证据（哈希/偏移/命令回显）
4. 怎么复现
5. 怎么修/怎么防

想核对原始证据就看同目录的 `evidence.md`（命令原文 + 真实回显 + 哈希），提取出来的文件在 `artifacts/`。

## 目录说明

```
drop/                 你放文件的地方
done/                 处理完的输入（自动移动）
runs/                 所有报告和证据
  INDEX.md            总索引（进度看这里）
  <时间>-<文件名>/
    report.md         给小白看的结论
    evidence.md       给复核看的原始证据
    artifacts/        提取物、截图、抓包
    meta.json         输入哈希、类型、工具链、耗时
```

## 常见问题

**放了文件，智能体没反应？**
确认文件在 `drop/` 根下（不是子文件夹），然后在对话框发「开始」。还不行就发「继续」。

**报告里写「未执行」或 `NO_OUTPUT`？**
说明那一步的工具没装、被目标挡住、或需要授权。报告里会留下一条可直接复现的命令；补上环境后把文件从 `done/` 移回 `drop/`，删掉 `runs/INDEX.md` 里对应那一行，再发「开始」。

**同一个文件想重跑？**
默认按 sha256 去重。把文件从 `done/<run-id>/` 移回 `drop/`，删掉 `runs/INDEX.md` 里对应行，再发「开始」。

**可以一次丢很多个吗？**
可以，按文件名顺序排队。想先跑某个就改文件名加前缀 `01-`、`02-`。

**报告能直接给客户看吗？**
`report.md` 是结论版；对外交付前把 `evidence.md` 里的内网地址、凭据、真实 IP 脱敏。

## 管理员：第一次部署（只做一次）

前置：已安装 `dsh-purge`（提供 `redteam_*` 工具层与技能根）；没有它预设会挂载失败。

1. 备份现有预设目录。
2. 把本目录 `redteam-preset/` 下的三个文件复制到 DeepSeek Harness 的预设目录（例如 `%DSH_HOME%\.agent-presets\redteam\`，或 `dsh-purge` 插件的 `presets/redteam/`）。
3. 重启 DSH；在预设下拉里应看到「鲲鹏·一键渗透逆向」。
4. 在仓库根建好 `drop/`、`done/`、`runs/`（本仓库已带）。
5. 跑一次 `preset-lint.py --preset <本目录>/agent.cordis.yml`，确认结构体检通过。

## 边界（必须知道）

- 只处理 `drop/` 里写明的目标；智能体不会扩段、不会扫旁站、不会碰无关资产。
- 证据只认真实回显/哈希/偏移；没跑的命令会标「未执行」，不会编造。
- 只对你拥有或已获书面授权的目标使用；授权范围写进目标文本，智能体会按它执行。
